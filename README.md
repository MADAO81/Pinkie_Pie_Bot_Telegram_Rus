 🎈 Пинки Пай — Telegram бот

Дружелюбный бот с интеграцией OpenAI GPT-4-turbo для общения в стиле персонажа из "Дружба — это чудо".

[![Deploy on SprintBox](https://img.shields.io/badge/Deploy-SprintBox-blue)](https://sprintbox.ru)

## ✨ Возможности

### 🎯 Базовый функционал
- 💬 **Общение с ИИ** в стиле Пинки Пай
- 🎙️ **Голосовые сообщения** (распознавание через Whisper)
- 🖼️ **Анализ изображений** (GPT-4 Vision)
- 🧁 **Рецепты выпечки** (парсинг andychef.ru)
- 🌤️ **Настроение от погоды** (Яндекс Погода)
- 😄 **Шутки, песенки и подбадривания**
- 📅 **Хранение истории** диалогов (30 дней)

### 🌈 Особенности характера
- Дружелюбная, энергичная и жизнерадостная
- С вероятностью 20% грустит в плохую погоду
- Работает ежедневно с 9:00 до 20:00
- Реагирует на фото и голосовые с вероятностью 20%

## 🚀 Установка

### Локальный запуск
```bash
# Клонирование репозитория
git clone https://github.com/your-username/pinkie-pie-bot.git
cd pinkie-pie-bot

# Установка зависимостей
pip install -r requirements.txt

# Настройка переменных окружения
cp .env.example .env
nano .env  # Заполните своими ключами

# Запуск
python run.py
